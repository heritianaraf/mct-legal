PAGES LÉGALES — BOT MCT

Fichiers :
- index.html : Conditions d’utilisation
- privacy.html : Politique de confidentialité

AVANT PUBLICATION
1. Remplacez [CONTACT] par une adresse e-mail que vous consultez.
2. Vérifiez le code réel du bot : données lues/enregistrées, fichiers ou base de données, logs, durée de conservation, hébergeur et services tiers.
3. Modifiez la politique pour qu’elle corresponde exactement aux pratiques réelles. Le texte fourni est un modèle de départ, pas un avis juridique.

PUBLIER GRATUITEMENT AVEC GITHUB PAGES
1. Connectez-vous à https://github.com/ et créez un nouveau dépôt public, par exemple mct-legal.
2. Renommez index.html en terms.html (facultatif) ou gardez-le comme page d’accueil. Pour obtenir deux URL simples, vous pouvez garder index.html pour les conditions et privacy.html pour la confidentialité.
3. Téléversez index.html et privacy.html à la racine du dépôt, puis cliquez sur Commit changes.
4. Ouvrez Settings > Pages.
5. Dans Build and deployment, choisissez Deploy from a branch, puis la branche main et le dossier /(root). Enregistrez.
6. Attendez la publication. Les liens seront généralement :
   https://VOTRE-NOM.github.io/mct-legal/
   https://VOTRE-NOM.github.io/mct-legal/privacy.html
   Remplacez VOTRE-NOM par votre identifiant GitHub et vérifiez que les deux pages s’ouvrent avant de les coller dans Discord Developer Portal.
